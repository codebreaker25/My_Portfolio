# Akash Gupta — Portfolio

Interactive, terminal-themed portfolio for **Akash Gupta**, Security Engineer (VAPT · Offensive Tooling · AI-in-Pentesting).

🔗 **Live:** https://codebreaker25.github.io/My_Portfolio/

## Features
- Fully interactive in-browser **terminal** — type `help` to explore (`whoami`, `projects`, `ctf`, `skills`, `contact`, plus hidden commands 🚩 and a `matrix` easter egg).
- Command history (↑/↓), Tab autocomplete, and a maximizable shell.
- A clean, scrollable visual portfolio below the terminal for recruiters who prefer to browse.
- No build step, no dependencies — pure HTML/CSS/JS. Served straight from GitHub Pages.

## Structure
- `index.html` — page markup and content
- `style.css` — terminal / offensive-security theme
- `terminal.js` — interactive shell engine + hero typing + matrix rain
